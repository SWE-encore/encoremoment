# Encore Moment - Submission A

This is an IEEE LaTeX transcription of the revised Submission A document supplied by the team, prepared on 2026-11-06. It preserves the original smart-TV proposal, stakeholder discussion, four-member role table, 22 requirements/objectives (EIR 1–3, FR 1–12, PR 1–4, NFR 1–3), and 27 references. The later PC-first specification is maintained separately in `../submission-b/`.

## Build

Run `latexmk -pdf main.tex` from this folder, or upload the complete source package to Overleaf and select `submission-a/main.tex`. The official IEEEtran class and the vector role-table asset are included. The references are in `references.tex`; BibTeX is not required.

## Source and transcription

- Text source: `Encore_Moment_submission_for_a_revised.odt`.
- Role-table artwork: the matching `Encore_Moment_submission_for_a_revised.pdf`, page 3. The existing table is reused; it has not been redesigned.
- The text is editable in `sections/`. Paragraph fragments caused by the original page layout were joined without changing the wording. Typesetting, citation links, and pagination were adapted to IEEEtran.
- The original reference wording and access dates are retained as historical submission content; the references were not re-researched during conversion.
- GitHub publication is separate from LMS submission and the printed copy.
